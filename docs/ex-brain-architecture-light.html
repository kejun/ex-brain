ex-brain 整体架构

基于 seekdb 的个人知识库 CLI — 智能编译 · 时间线 · 实体链接 · 混合搜索 · MCP

核心技术栈

  • seekdb 嵌入式数据库（全文 + 向量混合检索）
  • @ax-llm/ax 框架（Ax Signature + GEPA 优化）
  • @modelcontextprotocol/sdk（MCP Server）
  • Bun / Node.js 运行时

AI 能力

  • 智能编译（Compiler）— 自动更新 Compiled Truth
  • 时间线提取（Timeline Extractor）— 多格式日期解析
  • 实体链接（Entity Linker）— 10 种关系类型识别
  • 统一降级（Fallback）— LLM 不可用自动回退

数据模型

  • pages / links / timeline_entries / page_tags
  • raw_data（原始来源追溯）
  • ingest_log（文档摄取日志）
  • ebrain_pages（向量 + 全文混合检索集合）
