知识图谱 + RAG 融合查询流程

OceanBase AI 助理 · Graph-Guided Retrieval · 并行融合架构

分支 ①：知识图谱查询

  • • 实体识别 → 提取参数/组件/版本号
  • • 图谱查询 → 获取结构化事实
  • • 输出：实体 + 关系 + 属性 + 溯源链
  • • 消除：实体混淆、数值编造、过时信息

分支 ②：RAG 文档检索

  • • 查询重写 → 口语转结构化查询
  • • 多路检索 → Vector + BM25 + 参数表
  • • 输出：原始文档 Chunks + 相似度分数
  • • 消除：信息遗漏、上下文不足

融合 + 校验

  • • 图谱事实 + 文档 Chunks → 统一 Prompt
  • • Self-RAG Verifier → 检查回答有文档支撑
  • • 矛盾检测 → 冲突则降级置信度
  • • 分级输出 → High/Medium/Low 三种策略
