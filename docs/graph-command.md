# ebrain graph 命令

启动交互式知识图谱可视化 Web 服务器。

## 用法

```bash
ebrain graph                    # 启动在 http://localhost:3000
ebrain graph --port 8080        # 指定端口
ebrain graph --open             # 自动打开浏览器
```

## 功能

### 1. 交互式图谱

- **节点**: 页面实体（公司、人物、项目等）
- **边**: 实体之间的关联关系
- **颜色**: 按类型区分（公司=蓝色，人物=绿色，项目=橙色等）

### 2. 操作

- **点击节点**: 查看详情面板
- **双击节点**: 聚焦相关节点
- **拖拽**: 移动节点
- **滚轮**: 缩放
- **搜索**: 在侧边栏搜索节点

### 3. 工具栏

- **Fit View**: 适应窗口大小
- **Reset Filters**: 重置类型过滤器
- **Toggle Physics**: 开关物理引擎

### 4. 侧边栏

- **节点列表**: 按类型筛选
- **搜索框**: 快速查找节点
- **类型过滤器**: 显示/隐藏特定类型

### 5. 详情面板

点击节点后显示：
- Compiled Truth 预览
- 出链（指向其他页面）
- 入链（被其他页面引用）
- 时间线事件

## API 端点

```bash
# 获取图谱数据
GET /api/graph

# 获取节点详情
GET /api/node/<slug>
```

## 技术栈

- **后端**: Bun.serve()
- **前端**: vis.js Network
- **样式**: 暗色主题，响应式布局
