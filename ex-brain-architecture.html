Ex-Brain 系统架构

Personal Knowledge Base CLI + MCP Server powered by SeekDB & Ax-LLM

CLI 入口层

  • • cli.ts → Commander.js 注册 13+ 子命令
  • • MCP Server: 20 个 tools + 2 个 resources (stdio 传输)
  • • Graph Server: Bun.serve + vis.js 交互式知识图谱

AI 智能层

  • • AIPipeline: 统一 LLM 调用生命周期管理 (forward → parse → transform → fallback)
  • • Compiler: 语义化 truth merge + 冲突检测
  • • Entity Link: 实体关系抽取 (6 种实体 × 10 种关系)
  • • Timeline Extractor: 时间线事件自动提取

SeekDB 统一存储

  • • SQL 引擎: 6 张关系表 (pages, links, raw_data, timeline_entries, page_tags, ingest_log)
  • • 向量集合: hybridSearch + KNN 语义检索
  • • Embedding: 本地 Hash(默认) / OpenAI-compatible(DashScope 1024d)
  • • 嵌入式或远程模式，自动重连

文档处理层

  • • Document Loader: PDF(unpdf) / DOCX(mammoth) / HTML / JSON / URL fetch
  • • Markdown Parser: frontmatter 解析, wiki-style 链接提取, 时间线行提取
  • • 支持本地文件和远程 URL, 自动 MIME 检测 + magic number 校验
