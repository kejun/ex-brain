ex-brain Architecture

Personal knowledge base CLI — intelligent compilation, hybrid search, entity linking & MCP server

Client Interfaces

  • • CLI — 20+ Commander.js commands: put, get, search, query, compile, import, export, ingest, graph, serve
  • • Graph Web UI — Bun HTTP server + vis-network, renders knowledge graph at localhost:3000
  • • MCP Server — 14 tools over stdio transport (page CRUD, search, query, compile, timeline, tags)
  • • MarkSnip — Chrome extension for web clipping → Markdown import

Backend Core & AI Engine

  • • BrainRepository — Central data access: Page CRUD, hybrid search, vector query with freshness boost
  • • Truth Compiler — Ax Signatures with LLM for intelligent append/update/replace of compiled truth
  • • Entity Link Extract — 6 entity types × 11 relation types with confidence scoring & auto-linking
  • • Timeline Extract — AI-powered event extraction with date, summary, and importance ranking
  • • Embedding Factory — Local hash (offline default) or OpenAI-compatible (DashScope 1024d)

Data Storage — SeekDB

  • • Embedded MySQL — 6 SQL tables: pages, links, timeline_entries, raw_data, page_tags, ingest_log
  • • Vector Collection — ebrain_pages with hybrid search (full-text + vector similarity)
  • • Deploy modes — Local .db file or remote server via EBRAIN_SEEKDB_HOST env
  • • Auto-reconnect — Built-in retry logic with exponential backoff for connection errors
